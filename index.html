⚙️ Hubungkan ke Google Sheets

Masukkan URL Web App dari Google Apps Script agar dashboard membaca data Anda secara real-time dan otomatis terupdate setiap 5 menit.

⚠️ Jika sudah pernah deploy sebelumnya:
1. Buka Apps Script → Deploy → Manage Deployments
2. Klik ✏️ Edit → pilih New version → klik Deploy
3. Copy URL baru → paste di atas

Jika belum pernah deploy:
1. Deploy → New Deployment → Type: Web App
2. Execute as: Me  |  Who has access: Anyone
3. Klik Deploy → authorize → copy URL
